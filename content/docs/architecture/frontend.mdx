## 1. Protocol Dashboard (`/dashboard`)

The **Protocol Dashboard** serves as the central command center for monitoring systemic risk, collateralization ratios, and global protocol health across all asset pools.

### Key Metrics Monitored

| Metric | Category | Description |
| :--- | :--- | :--- |
| **Total Value Locked (TVL)** | Liquidity | Aggregate value of collateral deposited across all lending pools (ETH, WBTC, wstETH) priced via real-time Chainlink feeds. |
| **Outstanding Debt** | Solvency | Total synthetic and stablecoin debt borrowed against active collateral positions (USDC, USDT, DAI). |
| **Active Positions** | Risk | Total count of live borrower debt positions continuously scanned for solvency. |
| **Liquidatable Positions** | Alert | Immediate alert counter showing all positions currently crossing the threshold where `HF < 1.00`. |
| **Settled Volume** | Throughput | Cumulative dollar volume of liquidations settled deterministically through Reforge batch auctions. |
| **Bad Debt Prevented** | Security | Total protocol insolvency prevented compared to baseline mempool congestion failure rates. |

### Protocol Solvency Telemetry

| Metric | Calculation / Source | Update Frequency | Purpose |
| :--- | :--- | :--- | :--- |
| **Global Collateral Ratio** | `Total Collateral Value / Total Borrowed Debt` | Per block (12s) | Measures macro protocol solvency buffer. |
| **At-Risk Debt (HF &lt; 1.05)** | Sum of debt for positions with `HF ∈ [1.00, 1.05)` | Real-time WebSocket | Early warning queue for incoming liquidation volume. |
| **Protocol Recovery Rate** | `(Recovered Collateral / Defaulted Debt) × 100%` | Per settled auction | Evaluates liquidation execution efficiency. |
| **Average Auction Duration** | Block timestamp delta (End - Start) | Historical indexer | Monitors batch clearance latency against volatility. |

Simulated execution across 1,000 synthetic liquidation events demonstrates substantial economic advantages:

| Performance Metric | Conventional PGA | Reforge Batch Auction | Variance | Economic Impact |
| :--- | :--- | :--- | :--- | :--- |
| **Gas Cost / Liquidation** | **$142.00** | **$61.00** | <span className="text-emerald-500 font-bold">-57.0%</span> | Massive reduction in network congestion and wasted compute. |
