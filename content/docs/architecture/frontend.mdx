## Protocol dashboard

Shows:

```
TVL
Outstanding debt
Active positions
Liquidatable positions
Total liquidations
Protocol recovery
Bad debt
```

### Liquidation marketplace

Something like:

```
OPEN OPPORTUNITIES

Position       Debt       HF      Est. Profit    Status

0x7A...        $8,200    0.98       $410         OPEN
0x19...        $21,400   0.94       $1,100       OPEN
0x42...        $4,200    0.99       $190         OPEN
```

Clicking one displays:

```
Collateral
Debt
Oracle price
Health factor
Liquidation bonus
Estimated gas
Expected profit
DEX price impact
Auction state
Competing bidders
```
