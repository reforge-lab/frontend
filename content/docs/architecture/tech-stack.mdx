The Reforge platform leverages modern, industry-standard tooling across every layer of the architecture, optimized for developer velocity, type safety, deterministic testing, and high-performance event processing.

---

## Detailed Technology Breakdown

### 1. Smart Contract & Blockchain Layer

| Technology | Version / Tool | Category | Role & Purpose |
| :--- | :--- | :--- | :--- |
| **Solidity** | `^0.8.24` | Language | Core smart contract development with custom errors and transient storage support. |
| **Foundry** | `forge` / `cast` | Toolchain | High-speed compilation, fuzzing, differential testing, and contract deployment. |
| **Anvil** | Local Node | Testing | Fast local Ethereum node with programmable RPC state manipulation and flash loan mocking. |
| **OpenZeppelin** | `v5.0` | Libraries | Standard ERC-20, SafeERC20, ReentrancyGuard, and Ownable implementations. |
| **Sepolia Testnet** | Ethereum L1 | Network | Public testnet deployment venue for end-to-end multi-agent auction trials. |

---

### 2. Backend Infrastructure & Real-Time Pipeline

| Technology | Version / Tool | Category | Role & Purpose |
| :--- | :--- | :--- | :--- |
| **Node.js** | `v22 LTS` | Runtime | High-performance asynchronous execution runtime. |
| **TypeScript** | `v5.x` | Language | Strict end-to-end typing across data schemas, API contracts, and RPC calls. |
| **Fastify** | `v4.x` | Web Framework | Low-overhead HTTP REST API server with built-in JSON schema validation. |
| **viem** | `v2.x` | Web3 Client | Modular, lightweight Ethereum client maintaining persistent WebSocket subscriptions. |
| **Redis & BullMQ** | `v7.x` | Message Queue | In-memory job queue managing high-priority liquidation discovery and auction timers. |
| **PostgreSQL** | `v16` | Database | Persistent relational storage for historical auctions, bids, and simulated experiments. |
